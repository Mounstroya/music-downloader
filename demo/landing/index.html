Busca una canción. Llega a Navidrome con portada, letra y etiquetas.

Music Downloader busca los metadatos en Spotify o Deezer, encuentra el audio en YouTube con yt-dlp y lo guarda ordenado en tu biblioteca de Navidrome. También compara tus playlists con lo que ya tienes y te deja escuchar cada descarga antes de aprobarla.

Probar la demo → Instalar con Docker

La demo corre la interfaz real con datos de ejemplo: no descarga nada ni pide llaves.

Qué hace

🔎 Busca con buenos metadatos

Canciones y álbumes desde Spotify o Deezer. Sin llaves de Spotify funciona solo con Deezer.

🎯 Elige bien en YouTube

Califica a los candidatos de YouTube Music y te pregunta cuando no hay una coincidencia clara.

🏷️ Etiqueta y ordena

Artista, álbum, número de pista, portada y letras sincronizadas (.lrc), en Artista/Álbum/.

📋 Revisa playlists

Importa una playlist de Spotify o Deezer, ve cuáles ya tienes, descarga las que faltan y apruébalas al escucharlas.

📊 Cola con progreso

Descarga canciones sueltas o álbumes completos y sigue el avance de cada una.

🍪 Menos bloqueos de YouTube

Sube las cookies de una cuenta de YouTube desde la página /cookies para evitar el "confirma que no eres un bot".

Instalar

Necesitas Docker. La imagen se publica en ghcr.io/mounstroya/music-downloader:latest y trae todo (Python, ffmpeg, yt-dlp). Cambia /ruta/a/tu/musica por la carpeta de música de Navidrome.

Opción A · docker run

mkdir -p md-data
docker run -d --name music-downloader \
  --restart unless-stopped \
  -p 8000:8000 \
  --user "$(id -u):$(id -g)" \
  -v /ruta/a/tu/musica:/music \
  -v "$PWD/md-data":/app/downloads \
  -e NAVIDROME_MUSIC_PATH=/music \
  -e DOWNLOAD_DIR=/app/downloads \
  -e HOME=/app/downloads \
  -e XDG_CACHE_HOME=/app/downloads/.cache \
  -e METADATA_SOURCE=deezer \
  ghcr.io/mounstroya/music-downloader:latest

Opción B · docker-compose.yml

services:
  music-downloader:
    image: ghcr.io/mounstroya/music-downloader:latest
    container_name: music-downloader
    restart: unless-stopped
    user: "1000:1000"            # tu usuario: id -u / id -g
    ports:
      - "8000:8000"
    volumes:
      - /ruta/a/tu/musica:/music     # carpeta de música de Navidrome
      - ./md-data:/app/downloads     # base de datos, temporales y cookies
    environment:
      NAVIDROME_MUSIC_PATH: /music
      DOWNLOAD_DIR: /app/downloads
      HOME: /app/downloads
      XDG_CACHE_HOME: /app/downloads/.cache
      METADATA_SOURCE: auto          # auto | spotify | deezer
      # Opcional: Spotify (si no pones llaves, se usa Deezer)
      # SPOTIFY_CLIENT_ID: ...
      # SPOTIFY_CLIENT_SECRET: ...
      # SPOTIFY_REDIRECT_URI: http://127.0.0.1:8000/callback
      # Opcional: pedir a Navidrome que reescanee al terminar
      # NAVIDROME_API_URL: http://navidrome:4533
      # NAVIDROME_USERNAME: admin
      # NAVIDROME_PASSWORD: ...
      # Opcional: formato y calidad por defecto
      # OUTPUT_FORMAT: mp3
      # AUDIO_QUALITY: "192"

Crea antes la carpeta (mkdir -p md-data) para que sea de tu usuario; luego docker compose up -d y abre http://localhost:8000.

Variables

VariablePara qué
NAVIDROME_MUSIC_PATHCarpeta de música dentro del contenedor (/music). Monta ahí la de Navidrome.
DOWNLOAD_DIRTemporales, base de datos de playlists y cookies de YouTube. Móntala para no perderlas.
METADATA_SOURCEauto (Spotify si hay llaves, si no Deezer), spotify o deezer. Deezer no necesita llaves.
SPOTIFY_CLIENT_ID, SPOTIFY_CLIENT_SECRETOpcionales. Créalas en developer.spotify.com.
NAVIDROME_API_URL, NAVIDROME_USERNAME, NAVIDROME_PASSWORDOpcionales, para lanzar el escaneo de la biblioteca al terminar cada descarga.
OUTPUT_FORMAT, AUDIO_QUALITYOpcionales. Formato (mp3, m4a, opus, ogg, flac) y kbps por defecto.

Si YouTube empieza a pedir "Sign in to confirm you're not a bot", entra a /cookies en tu instalación y sube la sesión de una cuenta secundaria. Más detalles en el README.

In English

Music Downloader is a self-hosted web app: search songs or albums with Spotify or Deezer metadata, download the audio from YouTube with yt-dlp, tag it (cover art, synced lyrics) and drop it into your Navidrome library. It can also compare a Spotify/Deezer playlist against your library and let you review each download. Try the demo (sample data, nothing is downloaded) or run ghcr.io/mounstroya/music-downloader:latest with Docker as shown above. For personal use only; respect copyright.
